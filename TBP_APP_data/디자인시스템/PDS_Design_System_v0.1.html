01. Design Principles

Fast on Field

운동장에서 한 손으로 빠르게. Class Log는 20~30초 내 입력.

Evidence over Impression

“잘했어요”보다 실제 행동과 관찰 기록을 먼저 보여준다.

Professional, not Cold

스포츠 퍼포먼스 도구의 전문성에 유소년 브랜드의 친근함을 더한다.

Brand sentence
선수의 성장을 기록하는 TBP의 코칭 시스템.

12. Accessibility & Field UX

  • 최소 터치 영역 44×44px
  • Body text WCAG AA 대비 목표
  • Color만으로 상태 구분 금지
  • 명확한 Focus 표시
  • Form Label 필수
  • Hover 의존 금지
  • Error는 field 주변에도 표시
  • 이미지 alt 제공
  • 모바일 가로 스크롤 지양
  • Motion 감소 설정 고려

16. Do / Don't

Do

  • Navy = 구조 / Primary Action
  • Blue = Active / Selected
  • Orange = 제한적 강조
  • 실제 Observation 중심
  • 모바일 한 손 조작
  • 충분한 White Space

Don't

  • 화면 전체 Vivid Blue
  • Orange CTA 남발
  • 모든 요소 Pill
  • 야구 장식 남발
  • Skill 점수화/랭킹
  • Desktop Table을 Mobile에 그대로 축소

17. Definition of Done

이 Design System v0.1에서 Brand Color, Typography, Spacing, Shape, Interaction, Base Component, PDS Domain Component, State, Accessibility, Mobile Rule까지 정의했다.

다음 단계
이 시스템을 그대로 사용해 Dashboard부터 Monthly Report까지 7개 화면의 Low/Mid Fidelity Wireframe을 제작한다. 화면에서 새로운 패턴이 필요하면 임의 스타일을 만들기보다 Design System에 추가 여부를 먼저 판단한다.
