1. 화면의 역할

Players는 단순 회원 명단이 아니라 “현재 내가 성장 관리를 하고 있는 선수를 찾는 화면”이다.

핵심 질문
① 누구를 관리하고 있나?　② 원하는 선수를 바로 찾을 수 있나?　③ 지금 이 선수의 목표는 무엇인가?　④ 마지막으로 언제 기록했나?

목록 화면에서는 상세 Skill, 보호자 연락처, 긴 코치 메모 등 과도한 정보를 노출하지 않는다.

2. 핵심 Flow

선수 찾기

Players→이름 검색→Player Card→Player Detail

클래스별 확인

Players→클래스 필터→소속 선수

신규 등록

Players→+ 선수 등록→Player Create

3. 정보 우선순위

  1. Header + 선수 등록
  2. 이름 검색
  3. 클래스 / 상태 필터
  4. 현재 조건의 선수 수
  5. Player List
  6. 추가 등록 CTA
  7. Global Navigation

SCR-PLAYERS-001 기본값은 전체 클래스 + 활동 중이다.

14. Round 2 결정사항

Players = 성장 관리 대상 탐색 화면
이름을 찾고, 현재 목표를 확인하고, Player Detail로 들어가는 데 집중한다.
  • 기본: 활동 중 + 전체 클래스
  • 검색: 선수 이름
  • 필터: 클래스 + 상태
  • 정렬: 가나다순
  • 퇴원/휴원: 삭제 대신 inactive
  • 상세 성장 데이터는 Round 3에서 정의
