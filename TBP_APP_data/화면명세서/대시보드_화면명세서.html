Dashboard 화면 명세서 v0.1

코치가 로그인 후 오늘의 수업, 진행 중인 기록, 미작성 업무, 월간 리포트 현황을 즉시 파악하고 다음 행동으로 이동하기 위한 업무 홈 화면.

SCR-DASHP0CoachMobile First

1. 화면의 역할

Dashboard는 분석용 통계판이 아니라 “지금 코치가 무엇을 해야 하는가”를 알려주는 업무 시작점이다.

핵심 질문 4개
① 오늘 어떤 수업이 있나?　② 지금 시작/재개할 수업은?　③ 빠진 기록은?　④ 이번 달 리포트는 얼마나 남았나?

매출, 복잡한 성장 차트, 코치 KPI, 결제·예약 현황은 MVP Dashboard에서 제외한다.

2. 핵심 사용자 흐름

수업 시작

로그인→Dashboard→다음 수업→수업 시작→Class Log

기록 보완

Dashboard→미작성 기록→대상 수업→기록 완료

월말

Dashboard→Report 진행률→Monthly Report

3. 정보 우선순위

  1. Header — 날짜 / 코치
  2. Primary Class — 진행 중 또는 가장 가까운 다음 수업
  3. 오늘 수업 목록
  4. 미작성 기록
  5. Monthly Report 진행률
  6. 빠른 실행 — 선수 등록
  7. Global Navigation

SCR-DASH-003 진행 중 수업이 있으면 예정 수업보다 우선한다.

9. 데이터 요구사항

원천 데이터 · Coach / Class / Class Session / Enrollment·Attendance / Observation·Class Log / Monthly Report

Dashboard 계산 데이터 · 오늘 수업, 진행 중 Session, 다음 수업, 기록 완료 수, 미작성 선수 수, 월 리포트 대상 수, Approved 수, 진행률

DATA-DASH-001~004 Class Log 저장, 수업 시작/종료, Report 승인 후 Dashboard로 돌아오면 해당 수치와 상태가 최신값으로 반영되어야 한다.

10. Mobile UX 요구사항

  • UX-DASH-001 360px 이상 모바일 viewport에서 핵심 기능 사용 가능.
  • UX-DASH-002 주요 터치 CTA 높이 최소 44px 권장.
  • UX-DASH-003 현재/다음 수업 CTA를 빠르게 발견할 수 있어야 함.
  • UX-DASH-004 주요 정보에 가로 스크롤 금지.
  • UX-DASH-005 상태를 색상만으로 전달하지 않고 텍스트 병기.

14. Round 1 결정사항

Dashboard = 오늘의 업무 홈
현재 수업 → 다음 수업 → 미작성 기록 → 월간 리포트 순으로 업무 우선순위를 보여준다.
  • Mobile First
  • 리포트 진행률은 Approved 기준
  • 진행 중 Session 재사용
  • MVP Quick Action은 선수 등록
  • 다른 화면의 세부 정책은 해당 Round에서 확정
