Class Log 화면 명세서 v0.1

수업 현장에서 코치가 선수별 실제 행동을 30초 이내에 기록하고, 그 Observation을 Skill·영상·월간 리포트·다음 목표로 연결하는 PDS의 핵심 입력 화면.

SCR-CLASS-LOGP0 · CORE≤ 30 sec / PlayerMobile FirstField First

1. 이 화면이 PDS에서 가장 중요한 이유

수업→Observation→Skill→Media→Monthly Report→Next Goal
좋은 리포트보다 먼저 좋은 원본 기록이 필요하다.
Class Log에서 구체적인 행동이 꾸준히 쌓여야 PDS 전체가 의미를 갖는다.

2. 핵심 UX 원칙

  • 선수 1명 ≤ 30초
  • 모든 Skill 기록 강제 금지
  • 관찰하지 않은 내용 입력 금지
  • 한 선수 Observation 여러 개 허용
  • 횟수·Media는 선택
  • Skill 자동 승급 금지
  • 저장 후 다음 선수 즉시 이동

3. 최소 기록 Flow

선수→Skill→관찰→저장 & 다음

시도/성공과 Media가 필요하지 않은 일반 기록은 이 정도의 단계만으로 끝낼 수 있어야 한다.

필수 입력은 2개
Skill Area + Observation Text

8. 행동 기록 원칙

좋은 기록

  • 정면 공을 끝까지 보고 잡음
  • 반대발을 내디디며 던짐
  • 토스 공을 앞으로 강하게 보냄

피할 기록

  • 잘했음
  • 많이 늘었음
  • 집중력이 좋았음

9. Save & Next

IDAction동작
ACT-LOG-001저장 & 다음 선수저장 → 현재 선수 상태 갱신 → 다음 not_started present 선수로 이동.
ACT-LOG-002같은 선수 기록 추가저장 → 동일 선수 유지 → 새 Observation Form.
ACT-LOG-004다음 미작성 선수첫 번째 not_started + present 선수로 이동.
Primary Action은 “저장”이 아니라 “저장 & 다음 선수”다. 현장에서 여러 선수를 연속 기록하는 흐름을 최우선으로 한다.

10. Attempts / Successes

필요한 훈련에서만 10회 중 6회처럼 기록한다.

  • 0 이상 정수
  • successes ≤ attempts
  • attempts 없이 success 단독 입력 금지
  • 둘 다 비워도 저장 가능

11. Media

사진/영상은 Observation에 연결한다.

player_id · session_id · observation_id · skill_area

업로드 실패 ≠ 기록 실패
영상 업로드가 실패해도 저장된 텍스트 Observation은 유지한다.

12. Skill Ladder와의 경계

Class Log관찰 사실 저장Observation근거Skill Ladder코치 승인Level 변경
5/5 성공했다고 자동 승급하지 않는다.
Class Log는 사실을 저장하고, Skill Ladder는 누적 근거를 보고 코치가 현재 단계를 판단하는 역할이다.

14. Error / Data Loss 방지

저장 실패 → 입력 내용을 유지하고 다시 저장.

Media 실패 → Observation 유지 + 업로드 재시도.

작성 중 뒤로가기 → Draft 보존 또는 이탈 확인.

Session 없음 → 수업 목록으로 이동.

15. 현장 Mobile UX

  • 한 손 사용
  • CTA/Skill 버튼 44px 권장
  • 숫자 입력 numeric keypad
  • 현재 선수 이름 항상 명확
  • 저장마다 확인 Modal 금지
  • 느린 네트워크 저장 상태 표시
  • 작은 글씨/촘촘한 UI 회피

16. AI / Voice 확장 방향

음성→STT→AI 구조화→코치 확인→저장

“서준이 오늘 던지기 할 때 반대발을 잘 사용했고 다섯 번 중 네 번 정도 됐음.”

제안 → 던지기 / 반대발을 내디디며 던짐 / 4 of 5
AI는 없는 숫자를 만들거나 자동 저장하지 않는다.

초기 MVP에서는 제외 가능. 기본 Form만으로 서비스가 완전히 동작해야 한다.

20. Round 5 결정사항

Class Log = 관찰 사실을 빠르게 쌓는 화면
“많이 기록하는 것”보다 “현장에서 계속 기록할 수 있는 것”을 우선한다.
  • ≤30초 / Player
  • 유효 Observation 1개 = 선수 기록 완료
  • Observation당 Skill 1개
  • 여러 Observation 허용
  • 횟수/Media 선택
  • Save & Next 중심
  • 미작성 종료 허용 + 후속 보완
  • Skill 자동 승급 금지
