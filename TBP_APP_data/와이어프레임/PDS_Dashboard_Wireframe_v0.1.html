Dashboard 설계 의도

대시보드는 통계 화면이 아니라 코치가 오늘 해야 할 일을 바로 실행하는 업무 홈으로 구성했다. 현재/다음 수업을 가장 강하게 노출하고, 오늘 수업 → 미작성 기록 → 월간 리포트 → 빠른 실행 순으로 업무 우선순위를 유지한다.

01 · Primary Class

진행 중 수업이 있으면 진행 중이 최우선이며 CTA는 “기록 계속하기”. 없으면 가장 가까운 예정 수업과 “수업 시작”을 노출한다.

02 · Today Classes

시작 시간 오름차순. 상태는 scheduled, in_progress, completed, cancelled을 텍스트와 함께 표시한다.

03 · Incomplete Logs

미작성 선수 총 수와 클래스별 요약을 노출한다. 0명이면 CTA 대신 “오늘 기록을 모두 작성했어요.” 성공 상태를 표시한다.

04 · Monthly Report

완료율은 Approved / 대상 선수만 계산한다. Draft는 완료 수에 포함하지 않는다.

05 · Design Tokens

  • Primary: #0B2A4A
  • Active: #1546F5
  • Accent: #FF7A1A
  • Card radius: 12px
  • Primary CTA: 48px
  • Page padding: 16px

06 · Global Navigation

MVP는 홈 / 선수 / 수업 / 리포트 4개. Skill Ladder는 독립 메뉴가 아니라 Player Detail 내부 진입 구조를 유지한다.

상태 표현 샘플

예정진행 중완료 / Approved미작성 / Draft

색상만으로 상태를 전달하지 않고 반드시 텍스트를 함께 사용한다.

반응형 원칙

360–390px 모바일을 기준으로 설계하고, Desktop에서는 기능 우선순위를 바꾸지 않은 채 콘텐츠 최대 폭을 제한한다. Today Class와 업무 카드는 필요 시 2열로 확장한다. 주요 터치 영역은 최소 44×44px, Primary CTA는 48px을 유지한다.
