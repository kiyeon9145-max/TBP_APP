Player Detail 설계 의도

한 선수의 현재 상태와 성장 히스토리를 연결하는 PDS의 중심 화면이다. Overview만 보더라도 현재 목표, Skill, 최근 관찰, Media, 최근 Report를 빠르게 파악할 수 있도록 원본 데이터 전체가 아닌 핵심 요약을 우선 배치했다.

01 · Player Header

이름, 학년/연령, 투·타, 현재 클래스, 활동 상태만 우선 노출한다. •••에는 선수 정보 수정과 상태 변경을 배치하며 MVP에서 영구 삭제는 제공하지 않는다.

02 · Current Goal

대표 Current Goal은 한 시점에 1개다. 가장 중요한 코칭 행동이므로 Overview 상단에서 Navy Card로 강조한다. 변경 시 이전 Goal은 삭제하지 않고 History를 유지한다.

03 · Information Priority

선수 식별→현재 목표→현재 Skill→최근 변화→실제 Observation→Media→Report

Overview는 상세 원본을 모두 펼치는 화면이 아니다. 각 섹션의 상세 탐색은 해당 탭으로 넘긴다.

04 · Tab Navigation

Overview / 수업기록 / Skill / 영상 / Report 5개 탭. 모바일에서는 탭 영역만 가로 스크롤을 허용하고 페이지 전체의 가로 스크롤은 금지한다.

05 · Skill Summary

받기·던지기·치기·주루의 현재 Level만 요약한다. Level은 점수가 아닌 행동 단계이며 별점, 평균 대비 %, 랭킹 표현을 사용하지 않는다.

06 · Recent Change

최근 Skill 변경 1~3개를 보여준다. Skill Level은 Observation이나 AI가 자동 변경하지 않으며 코치 승인으로만 변경된다.

07 · Recent Observation

최신 Observation 3개를 기본 표시한다. 날짜·클래스·Skill Area·관찰 내용이 기본이고, attempts/successes는 데이터가 있을 때만 표시한다.

08 · Media / Report

최근 Media 최대 3개와 가장 최근 Monthly Report 1개만 Overview에 노출한다. 각각의 전체 History는 별도 탭에서 확인한다.

Skill 미평가

해당 Skill을 Level 1로 간주하지 않고 “미평가”로 명확히 표시.

기록 없음

수업 기록 / Media / Report별 Empty State와 해당 생성 Action 제공.

09 · Quick Action

＋ 기록 추가는 모바일 하단 Sticky Primary CTA다. 활성 Class Session이 있으면 해당 Class Log로, 없으면 별도 기록 Flow 또는 최근 수업 선택으로 연결한다.

10 · Data Integrity

  • Skill History 덮어쓰기 금지
  • Class Membership 과거 이력 유지
  • inactive 전환 시 성장 데이터 유지
  • Report는 해당 선수 데이터만 참조

Design System 적용

Primary 구조/CTA는 Navy 800 #0B2A4A, Active/Selected는 Blue 600 #1546F5, Surface는 White, Border는 Gray 200을 사용했다. Card radius 12px, Button 48px, touch target 44px+ 원칙을 유지한다. Player Detail은 독립 Bottom Navigation보다 상세 화면의 Back + Tabs + Sticky Action 구조를 우선한다.
