PDS · DATA ARCHITECTURE · v1.1

전체 ERD / DB Schema

Hi5와 동일한 분리형 개발 구조를 기준으로 수정한 PDS 데이터 아키텍처. Next.js는 UI, Backend는 비즈니스 로직과 Transaction, PostgreSQL은 원본 데이터와 성장 History를 담당한다.

제거
